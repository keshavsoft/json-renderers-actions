Ecosystem Architecture

In modern client-side architectures, responsibilities should be strictly divided into single-purpose primitives. json-renderers-actions acts as the consumer-facing coordinator that connects these three layers:

Layer 1: Presentation
json-renderers

Transforms declarative columns, data, and options into valid DOM nodes mounted inside a target container.

Layer 2: Event Delegation
dom-primitive-bindings

Maintains zero per-element event listeners. Binds exactly 1 listener to the container and matches bubbling targets with CSS selectors.

Layer 3: DOM Traversal
dom-primitive-engine

Walks the table hierarchy (tr → td) and cleanly maps cell text back into a structured JavaScript row object.

json-renderers-actions

Takes the actions object from the developer and automatically translates it into binding configurations for Layer 2 and extraction calls for Layer 3. The developer only interacts with pure data objects in clean callbacks.

The 4-Key Developer Contract

When rendering tables, developers only need to specify 4 declarative keys:

Key Type Description
data Array<Object> The dataset to render in the table body.
columns Array<Object> Column definitions containing field and name metadata.
options Object Table configuration (e.g. search bar, footer totals, pagination).
actions Object High-level action handlers: rowClick, searchKeydown, footerClick.

Usage Example

1. Standalone Usage with applyActions:

import applyActions from "json-renderers-actions";

applyActions("dom-render-container", {
  columns,
  actions: {
    rowClick: (data, event) => {
      console.log("Row clicked:", data);
    },
    searchKeydown: (query, event) => {
      console.log("Searching for:", query);
    },
    footerClick: (data, event) => {
      console.log("Footer clicked:", data);
    }
  }
});

2. Browser Script Tag (Global Access):

<script src="./dist/v1/min.js"></script>
<script>
  window.ks.jsonRenderersActions.applyActions("dom-render-container", {
    columns: columnsData,
    actions: {
      rowClick: (row) => alert("Selected: " + row.name)
    }
  });
</script>

Supported Action Handlers

  • rowClick(data, event): Triggered when any row action button (button[data-action="view"], .btn-row-action, or table row) is clicked. The callback receives the fully extracted row object mapped to columns.
  • searchKeydown(query, event): Triggered on keydown / input inside table search inputs (input[type="search"] or .table-search-input). The callback receives the trimmed query string.
  • footerClick(data, event): Triggered on clicks within table footer elements (tfoot button or .table-footer-action).
