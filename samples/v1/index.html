The 4-Key Contract

Developers only deal with 4 declarative keys: 

applyActions("dom-render-container", {
  columns,
  actions: {
    rowClick: (rowData) => console.log(rowData),
    searchKeydown: (searchData) => console.log(searchData),
    footerClick: (footerData) => console.log(footerData)
  }
});
